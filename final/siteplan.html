Website Project Plan - Lumina Learning

Project Subject

Subject: Lumina Learning – A Product Launch Site for a Modern Learning Management System (LMS)

Description of Planned Content

  • Dynamic Feature Showcase (interactive role-based toggle for Teachers vs. Students)
  • Interactive Course Preview (functional demo area with sample lesson card interaction)
  • Pricing Calculator (dynamic JavaScript tool calculating monthly costs based on user sliders/inputs)
  • Resource Library (responsive grid of educational articles layout via CSS Flexbox/Grid)
  • Contact & Demo Form (validated lead-capture form)

Reason for Selection

I chose this subject because an LMS product site requires a balance of high-end professional design and interactive functionality. It provides the perfect framework to meet course requirements: practicing responsive design through complex layouts, integrating JavaScript naturally via UI components like dynamic content filtering and a pricing estimator, and building a professional portfolio piece that mirrors a real-world freelance assignment.

Site Name

Example: Lumina Learning

This name represents clarity, modern digital education, and an illuminating user experience for both educators and learners.

Optional domain availability: luminalearning.com

Site Purpose

The site serves as a multi-page, responsive marketing and informational platform for a modern Learning Management System, designed to showcase advanced product features, offer interactive product and pricing estimates, provide educational resources, and convert prospective educational leads.

Scenarios

  • As a school administrator or instructor, how can I calculate our monthly subscription cost based on our active user count?
  • As an educator or student, how can I preview how the LMS interface works before requesting a demo?
